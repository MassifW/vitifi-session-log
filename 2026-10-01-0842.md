## Found

- **Mike's "can't use the app away from the laptop" was no signal**, and
  it is partly by design. On mobile data with signal everything works (the
  map caps its zoom to save data). With no signal, walks, picks and
  rackings are held; but the map draws only the phone's copy of the block
  outlines: the aerial photo is never kept, and only uploaded layers can be
  held offline. Holding LINZ's aerial photo on the phone (CC BY 4.0;
  Esri's terms bar it) is now on the suggested list.
- **Our security test had allowed `spatial_ref_sys` for the wrong
  reason**: it asked who could read the table (anyone, harmlessly), not
  who could write it.
- **Supabase's own advisor will keep flagging the table**: it looks for
  the row-level security switch, which only Supabase can turn on here.
