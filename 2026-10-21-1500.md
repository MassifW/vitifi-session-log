# 21 Oct 2026: the Compliance tables tried on a restored copy, then put on live

- The Compliance work built in a cloud session (forms, a library of the winery's own policies, a signature pad) had never run against a database. The full test suite on the laptop, with the live-database suites, found two real defects-in-waiting and four failures that were simply the new tables not existing on live yet. One real defect: the new code's database column lists were stored in constants, which the app's schema-contract test cannot read, so a renamed column would have gone unnoticed; they are now written out in the queries.
- The migration cannot be checked by its own test function until it exists, so it was first applied to a throwaway Supabase in Docker, restored from that morning's backup. The restore's own comparison passed. The migration's row-level-security test harness ran there: 28 of 29 passed. The one failure turned out to be a wrong expectation, not a hole: the database overwrites the author of a new record with the signed-in person, so naming someone else saves it as the caller rather than refusing it. The check was reworded, and a thirtieth added (the person named has no record from the attempt), rather than lowering the harness's minimum count.
- Applied to live after a dry run listing only that migration and a check that no backup was running; the full suite afterwards passed in full, with all live-database suites run.
- The winery's own policy and two SOPs were imported into the library as drafts (a dry run first; never overwrites). They stay drafts for the health-and-safety lead to review.
- Compared the winery's recall and bottling-line breakage procedures with the industry code of practice's model procedures; found a few differences in wording and one unfilled blank, for the winery to decide.
- Pasting the dev server's console into the chat exposed a login password, because Next.js's dev mode logs server-action arguments. Dev-only, but worth knowing: do not paste that output.
- Not done: nothing released; the remaining document imports and further builds wait for inputs.
