# 20 Oct 2026: barrel numbers

- A barrel can appear in the records as several vessels because its code was whatever was written on its head each time, so it looks empty between its own fills. Mike chose a permanent number issued by the app and fixed to the barrel on a tag, containing the year, with QR scanning wanted later.
- The number is the two-digit year, a dash and a running number that restarts each year. It is issued by the app, never reused, never changed. New barrels get it when added and it is shown large to stamp on the tag; a barrel already in the cellar gets it on request, and its old code is kept as a note of what is marked on the head. Tanks keep their names.
- Adding something that looks like an existing barrel now warns first. The "All records" download includes the number and the head marking.
