# Cellar trays in the dry goods planner

Mike asked for cellar trays in the bottling dry goods planner: one tray for each layer of bottles or magnums, three
for a full pallet.

- The planner now counts cellar trays from the layers each size stacks to (a part layer counted whole), as one line
  for the run with no spare, since trays are reused.
- Each bottle size has a "Cellar trays" tick; loose 750s and magnums start ticked, cartons do not. A phone's saved
  packing from before the change is read the same way.
- What is on hand comes from the existing "Cellar trays" item on Stock's dry goods list, so the current count is
  entered there with a stock count rather than typed into the planner.
- Open question: whether layer boards are still used between layers once trays are, or the trays replace them. The
  plan counts both until that is settled.
- Checked by unit tests, typecheck and build; not yet looked at in a browser.
