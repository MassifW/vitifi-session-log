# 2026-10-03 13:57 — The look passed; the header tidied; released

Mike looked at the app in the desktop app's side panel and passed the
new look ("the new look is good, happy to release it"). He asked for
three header changes:
- drop the "Current season" label, which scopes nothing and could
  confuse someone entering a past season's records;
- name the parent business where the breadcrumb said "Everything",
  useful for anyone with logins at more than one business;
- move the rest beside the logo to free up space.

## The header

- **The season label is gone.** It was a label, not a control. The two
  screens a season does scope have their own control where it acts.
- **The business's name tops the breadcrumb** ("<business> › <vineyard> ›
  …"), and the jump-list keeps "Everything". The name is a setting an
  owner enters on People, not code. It is read on the server alongside
  the signed-in check, so the page waits for no extra question. Unset, it
  reads "Everything".
- **Beside the logo.** The first attempt put everything in a column to
  the logo's right. It assumed a 375 px phone, and the side panel is
  280 px, so the name overlapped the logo. Rebuilt to wrap:
    - 280 px: three short rows (175 px, from about 460);
    - 390 px: two rows (107 px);
    - laptop: one row.
  Each width measured in the browser.
