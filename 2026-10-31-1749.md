# 31 Oct 2026 — The Safety layer widened into icons on the map

**Asked (Mike),** after the Safety layer was built but before it went live: maps are an essential part of compliance for any vineyard, so make this part of the core of the app. He wants a menu of icons anyone can place on their own map, made fun with old video-game pixel icons, and property boundaries considered too.

**Advised, and he chose "widen it first":**
- Change the table before it reaches live. Nothing is usable before a release anyway, and widening now avoids a rename on live and a renamed export file.
- Pixel icons, yes, with two rules. The safety icons keep ISO 7010's shapes and colours, so a seasonal worker and an auditor still recognise them. The fun stays on the map, while buttons and menus keep the brand.
- Property boundaries, yes, kept with each vineyard, as the next piece.

**Built**, on the same pull request, still not on live:
- **One table for every icon a winery places.**
  - A single list of icons lives in the database, with a matching copy in the code that a test compares: 27 icons in six groups (Safety, Water and irrigation, Buildings, Access, Equipment, Other).
  - A point can hold several icons, and its name is optional.
  - A point holding any safety icon can only be changed by owners, winemakers and the H&S lead. Anything else can also be changed by the vineyard team.
  - The rolled-back test harness grew to 26 checks. A vineyard hand can place, move and delete a pump, but can't add a first aid kit to it. A cellar hand can place nothing.
- **The icons.** Each one is a 16 × 16 picture written as text in the code, one letter per colour, drawn as crisp squares.
  - Safety icons sit on their ISO plates; the rest sit on cream tiles. They're original drawings, not copied from any game.
  - I looked at them large and at map size, then redrew the ones that read wrongly. A 16-pixel book looked like a face, so H&S information became an "i". The chemical store looked like a hill and became a drum. The vehicle looked like a face and became a tractor. The shed looked like a rubbish bin and became a barn.
- **On the map:**
  - An "Icons" button, which each phone remembers as on or off.
  - A key grouped by kind, where any group can be hidden.
  - "Add an icon" opens a grouped menu of tiles. Safety tiles are greyed out, with a line explaining why, for people who can't place them.
- **Records:** the export file moved next to the map layers in the Drive copy. The data guide, file directory, chronology, decisions log, manual and open items are all updated.

**Waiting:**
- Mike's yes for the migration on live, then the seed.
- After that: the property boundary (from New Zealand's public title outlines, or drawn by hand), lines and areas such as power lines, waterways and no-go zones, and the printed map.
