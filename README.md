# VITIFI session log (public)

VITIFI is a production-tracking app for a boutique winery, built with Claude Code. This is the public record of that work: what was decided, what was built, what was found, and the reasoning behind it.

This is a companion to a private, detailed log kept alongside the app's own source code. Entries here withhold exactly six things: block layouts, vine counts, yields, spray products and rates, client names, and certification details. Everything else is fair game, including feature names, vendor names (LINZ, Harvest, etc.), technical findings, and the reasoning behind decisions — this is ordinary agricultural software work, and an entry that can't be acted on because it's been filtered into vagueness has failed at the log's actual purpose. Where an entry genuinely can't be written without one of the six, that part stays in the private log only, and the entry says so rather than going vague around it.

Entries are dated `YYYY-MM-DD-HHMM.md`, one per session/response, oldest to newest.
