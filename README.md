# VITIFI session log (public)

VITIFI is a production-tracking app for a boutique winery, built with Claude Code. This is the public record of that work: what was decided, what was built, what was found, and the reasoning behind it.

This is a companion to a private, detailed log kept alongside the app's own source code. Entries here are deliberately filtered — no block layouts, vine counts, contract client names, certification details, spray products, or anything else about how the business operates. Where an entry can't be written without that kind of detail, it stays in the private log only.

Entries are dated `YYYY-MM-DD-HHMM.md`, one per session/response, oldest to newest.
