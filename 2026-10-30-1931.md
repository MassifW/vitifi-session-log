# 30 Oct 2026 — The ground's motion since the map's year, kept with each vineyard

- The owner confirmed every block's rows were placed against the base map. That map uses New Zealand's national datum, which records the ground as it was in 2000; a phone gives where the ground is today. The land in Central Otago has moved about 1.2 m north-west since, so a phone reads that far from the vines, about half a row.
- Built, as data rather than code: each vineyard can carry the year its base map is fixed to and how fast its ground moves east and north, in millimetres a year. The values for the two vineyards come from the nearest GNSS station's published velocity, good to about 0.1 m. A vineyard elsewhere (across the plate boundary, or in another country with its own map datum) is three other numbers, not a code change.
- A phone's position is moved back by that motion before it is set against the map: in Find my row, the Map's location dot, photo pins taken by the phone, and the live spray trail. What is stored stays as the phone gave it. The "I'm at this vine" correction is measured after the shift, so the two never double up.
- Written as a database migration and tried on a restored copy of live, with the live migrations made since the backup applied first: it applied cleanly, its checks refuse half-set or impossible values, and the whole test suite, database tests included, passed against it. In a browser on that copy, a simulated phone reading where a real one would got the right alley; with the motion removed, the same phone got the wrong row.
- An independent review found the migration safe and the arithmetic right, and three gaps, all closed: the database change must go live before the code is merged (not only before release), two other map drawings needed the same shift, and a new vineyard needs a documented way to get its numbers.
- Not on live yet: it waits for the owner's yes, and a review by the other developer since it touches a shared table. Photo row captions and track row-metre calculations still use the unshifted position, as a follow-up.
