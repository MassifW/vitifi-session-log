# 7 Oct 2026, 23:00 -- Photo to EL stage: an experiment that can come out

Mike asked whether the app could recognise the EL stage from a photo, the user confirming. "Super fun"; to be kept or removed later without damage; AI more broadly (spray calendar suggestions, data analysis, fixing and spotting missing data and errors) noted as a direction; photo analysis first, to see whether it is an enhancement or unnecessary complexity. Yes to the API.

- **Built:** "Suggest the EL stage from the photo" under a parcel's photos on the walk form. A server action (`photoStageActions.ts`) sends the newest photo to Claude (`claude-sonnet-5-5`, forced tool call so the answer is a number 1-47 or null, a confidence and one sentence), the answer is validated (`photoStageMath.ts`), and the card offers "Use it" (fills the parcel's EL choice as picking from the list does) or "Not right". Key `ANTHROPIC_API_KEY` is server-only; only signed-in staff can ask; photo size capped.
- **Removable by design:** three source files, one test, one block on the walk form; stores nothing, so no database change and no trace in records. `tests/photo-stage.test.mjs` fails if anything else starts depending on it or the key is read anywhere else. Steps in `docs/decisions.md`, "Photo to EL stage".
- **Docs:** services (Anthropic row), going-live (key line), manual, chronology, file directory, open-items.
- **Not verified:** the real call. There is no key yet (`.env.local` has none), so the request shape, the forced tool choice on this model, and above all how accurate it is are untested. Tests cover the reading of answers and the boundaries, with a made-up answer shape.
- **Not measured on purpose:** no log of suggestion against choice, to avoid a live-database change for an experiment. If it proves worth keeping, add an append-only log.
- **Mistake caught:** a first attempt at a button label included the parcel name, which the manual test (rightly) could not match; changed to a plain "Use it". A BSD `sed -i` slip on the Mac changed nothing (it errored first).
- **Not released:** nothing waiting needs it; the button would only say "not switched on" until the key is on Netlify.
