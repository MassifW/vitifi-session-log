# Pisa F's bays, prepared

After the post lines came back on the Vines picture, one Pisa block still had none: its sheet labels every line with its
own number, so the import had taken each vine's bay to be its vine number. The sheet draws that block's bays as heavier
cell borders instead. Reading those borders gives a regular pattern with a short end bay, and a migration now sets each
vine's bay from it, numbered from the first vine (the sheet gives no bay numbers there, so the numbering is ours).

It changes only that block's bay numbers; nothing else in the database stores a bay. Its arithmetic and its own checks
were tried read-only against the live data and pass. It waits for Mike to apply it, with a test that passes once he has.
