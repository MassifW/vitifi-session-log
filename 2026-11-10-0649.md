# Bay lines on the Vines picture

Mike asked for the bold post lines of the original vine sheets back on the Vines tab: they mark where each bay starts,
which helps you find your place in a row. Only the lines between bays, not the row ends, and no bay letters.

Every vine's bay number was already stored from the sheets, but the Vines tab never read it. Now a bold line is drawn
across a row wherever the bay number changes from one vine to the next, so neighbouring rows' lines join into a post line
across the block. The bay numbers are the vineyard's own (they need not start at vine 1, and an end bay can be short), so
the lines come from the stored numbers, never worked out from a vines-per-bay figure.

One block's stored bay numbers turned out to be its vine numbers, i.e. the bays were never really imported there. Rather
than a line between every vine, a block whose bay changes at most vines gets no lines; importing its real bays is a
data change waiting for Mike.

Checked with tests and in a browser against the live data on four blocks. No database change.
