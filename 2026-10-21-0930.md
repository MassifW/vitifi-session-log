# 21 Oct 2026: compliance forms, second pass

- The first pass was reviewed against the source documents the owner then supplied: the industry body's sustainability standard, the wine standards plan's Code of Practice, and the winery's own recall and bottling-breakage procedures. Which documents apply to which operation stays in the private log.
- Corrected: some clause references in the first pass had been carried over from an earlier summary and belonged to a different part of the standard. They are now taken from the standard's own text. Forms that existed only for a part of the standard that does not apply were removed.
- Added forms the Code of Practice contains that the first pass had missed: a recall risk assessment, a transfer checklist for bulk wine and juice, and a bottling-line breakage record with a re-processing record and a supervisor sign-off. The simulated recall now records the seven reconciliation figures the recall procedure asks for. Packaging is recorded by the standard's ten methods.
- 36 forms in all. The full test suite, typecheck and build pass; the SQL's own row-level-security checks still have not been run, because they need a database.

Reading every supplied document against the others found them, which is why the master list now has a "still to do in your own documents" section.
