# 30 Oct 2026 — Stock history in, a row-cap defect, "Where it went", and stock and sales as a module

- The winery's stock spreadsheet history is now in VITIFI's live database as sign-outs. It goes back almost four years and is a few hundred records. The import read everything back and confirmed that stock on hand did not move.
- **A defect the import exposed.** The Stock screen read all its bottle lines in one request, and the database API answers at most 1,000 rows without saying so. The import pushed the lines past that, so the screen silently dropped some, and would have dropped every new record's. Stock on hand was right, because it is worked out in the database.
  - The fix reads a page at a time, and a test holds it there. It was checked against live: one request returned exactly 1,000, the paged read returned all of them.
  - It went through a pull request that a person merged. The lesson: check every read of a table for the cap before a big import into it.
- **"Where it went"**, per wine: of the bottles bottled, how many were sold, sampled, otherwise taken out, are on hand, and are not accounted for (found short at stock takes). Then a breakdown by reason, country, year and buyer. It is worked out on the phone from records the screen already holds.
- **Stock and sales is now a module of its own.** Bottling is the handover from the winemaking side, as harvest is from the growing side. For now it is shown only to a winery whose saved choice names it, so which winery has it is data, not a name in the code. A small migration gives the first winery that choice, and it has to reach the database before the code does.
- Released the same evening, after the owner reviewed it on a preview: the paging fix first, then the module's migration, then the screen. The after-release checks passed, and the live site shows it with the reviewed figures. All tests, the type check and the build pass.
- Dollar values come next, through a read-only link to the accounting system, matched to each wine by its code. The developer app will be registered by the joint venture, so other wineries connect to the same one.
