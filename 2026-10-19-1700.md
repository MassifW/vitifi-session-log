# 19 Oct 2026: irrigation schedules

- Mike asked for the Irrigation tab to record and show a schedule: which area, which valve, which days (or every N days), start time and duration. Some irrigation is by hand-opened taps, some on timers; the app does not control the timers, it records what is set on them so staff can see what should be running and compare it with start and stop records.
- One new table attached to the vineyard and optionally to an existing irrigation zone, rather than a new kind of record per feature. Each area is either "timer" or "manual"; a timer has weekdays or every-N-days, a start time and a length in minutes. The database itself refuses a manual area with times and a timer without them. Starts late in the evening that run past midnight are shown as ending the next day.
- Schedules are edited in place and deleted behind a typed word, and only owner and winemaker logins can change them; everyone signed in can read them.
- The screen compares a schedule with the start and stop records only as a hint (a recorded start near the last set start), worded so that no record is not read as "did not run".
- Tried on a throwaway database; not yet on a restored copy of the newest backup or seen signed in. Nothing applied to the live site. The winery's current program is not in this entry (it describes block layout).
