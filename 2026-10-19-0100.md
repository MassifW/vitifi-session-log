# 18-19 Oct 2026: the 2023 vintage prepared for import

- The winery explained how its logs work: a tab per finished blend records the racking and blending, and a tab per ferment holds its press dates, so the days wine was moved can be read rather than guessed.
- Built the import for the 2023 vintage: the lots, one pick per fermenter, each barrel's filling (dated from its tank's own notes, and where there is no note dated "no later than"), the January 2025 rackings into five tanks and the February 2025 bottlings. It is written as one database change, kept apart from the live database until the winery says yes.
- Tried on a restored copy of the newest backup: it applies in one go, every barrel and tank of that vintage is empty afterwards, bottle stock is unchanged (the existing stock count stands), and the full set of checks passed against the copy.
- Findings for the winery to decide: one barrel code held two different wines in the same months in two logs; one lot's volume drops between the first and last tasting rounds with no record; two tanks' lots are swapped between the daily log and the weigh sheets; a wine already imported under another vintage appears again here.
- Not done: nothing applied to the live site; the screens not yet looked at; earlier vintages not started.

## Applied
- With the winery's go-ahead and no backup running, the 2023 import was applied to the live database by the winery itself. Read back afterwards: the expected number of lots, picks and fillings, the barrelled-down total equal to the log's own, no flagged lots, bottle stock unchanged, and the full set of checks passing against the live database. The screens have not yet been looked at.
