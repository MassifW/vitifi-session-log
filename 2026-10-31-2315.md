**Found and fixed while checking (my own mistakes):**
- The screen's "still open" flag was set false by React's development double mount and never set back, so the print was made and silently thrown away ("Starting…" for ever). It is now set on every mount.
- "Replace the picture" failed with "Maximum array nesting exceeded": React's server-action decoder counts a string's length against a 1,000,000 limit when it sits directly in the argument list (`arraySizeLimit`, Next 16.3). I first took it for a framework fault; the decoder's source says otherwise, and the library's own save passes the picture inside an object, which is not counted. The picture now goes inside an object.
- Page 2 drew page 1's icons again at a scale where they piled up; it now shows only what lies beyond page 1, with page 1 as a dashed box.
- The north arrow sat on an icon; the arrow and scale bar now take free corners.
- "(03) 000 0000" was refused as a phone number by both the screen and the migration (a leading bracket). Fixed in both; the migration is not on live.
- For someone who cannot edit, at a vineyard with nothing kept, the box ended "what is kept for this vineyard:" over nothing; the phrase now shows only when there is something.
